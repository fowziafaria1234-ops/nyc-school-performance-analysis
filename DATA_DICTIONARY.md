# Data dictionary

| Field | Meaning |
|---|---|
| school_id | Pseudonymous school identifier |
| school_name | Synthetic school name |
| borough | NYC borough category |
| year | Reporting year |
| enrolment | Student population |
| math_score / reading_score / writing_score | SAT-style subject results |
| attendance_rate_pct | Attendance percentage |
| economically_disadvantaged_pct | Cohort context measure |
| student_teacher_ratio | Students per teacher |
| graduation_rate_pct | Graduation percentage |
| composite_score | Mean of the three subject scores |
| outlier_flag | IQR-based performance outlier indicator |
