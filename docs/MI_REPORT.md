# Management Information Summary

## Executive message

The synthetic portfolio dataset shows meaningful performance variation across boroughs. **Manhattan** has the highest median composite score (580.4), while **Bronx** has the lowest (466.6). Attendance and performance have a positive correlation of **0.39** in the reconstructed data.

## Data quality

- Pre-cleansing completeness for required analysis fields: **96.1%**
- Post-cleansing completeness: **100.0%**
- Duplicate school-year records were removed.
- Missing scores were imputed using borough-and-year medians.
- Composite-score outliers were flagged using the IQR rule.

## Recommended action

Use borough comparisons as a starting point rather than a final judgement. Drill into school-level attendance, economic context and student-teacher ratios before designing targeted interventions.
